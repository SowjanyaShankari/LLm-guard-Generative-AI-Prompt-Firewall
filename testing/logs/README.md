# Logs

This directory stores runtime logs generated by the LLM-Guard Red Team Framework.

## Files

- attack_results.jsonl : Stores one JSON object per executed test case.
- application.log : General application execution logs.
- errors.log : Runtime and validation errors.
- performance.log : Performance metrics such as latency and throughput.

These files are generated automatically when the framework runs.

Do not manually edit generated log files.
