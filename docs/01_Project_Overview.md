# Project Overview

## Project Name

LLM-Guard – Generative AI Prompt Firewall

---

## Objective

LLM-Guard protects Large Language Models (LLMs) from Prompt Injection, Jailbreak attacks, unauthorized access, and malicious prompts.

The system acts as a reverse proxy between users and the AI model.

---

## Problem Statement

Modern AI models are vulnerable to:

- Prompt Injection
- Jailbreak Attacks
- Prompt Leakage
- Unauthorized API Access

LLM-Guard detects and blocks malicious prompts before they reach the LLM.
